## 👨‍💻 About Me

I'm a software engineer focused on building **clean, scalable, and maintainable systems** across the full stack. My work spans web applications, backend architecture, mobile development, and data-driven tooling — with an emphasis on writing code that stays reliable as it grows.

I care about **thoughtful architecture over quick fixes**, performance that scales with real usage, and interfaces that are as functional as they are refined. Whether I'm designing an API, structuring a database, or building a mobile experience, the goal is always the same: software that works predictably and is easy to reason about.

Currently exploring deeper systems design, data engineering workflows, and interactive/game development as extensions of core engineering practice.
